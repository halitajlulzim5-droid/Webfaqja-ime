# LH Electrical Power

This project is a static website for LH Electrical Power. It is designed to run as a GitHub Pages site.

## Publish live

1. Open the repository on GitHub.
2. Go to Settings → Pages.
3. Under Source, choose GitHub Actions.
4. Commit and push to the branch that contains the workflow.
5. The site will be available at:
   https://halitajlulzim5-droid.github.io/Webfaqja-ime/

## Files

- `index.html` — landing page
- `.github/workflows/deploy-pages.yml` — GitHub Actions workflow that publishes the site
- `.nojekyll` — disables Jekyll processing for static assets
